# Contributing

Bug reports and reproducibility questions are welcome through GitHub Issues.

Please include:

- the command that was run;
- the operating system and Python version;
- the package versions relevant to the error; and
- the complete traceback or failed comparison.

Do not upload provider-restricted imagery, repository credentials, access tokens, or local path inventories to an issue. Proposed code changes should preserve the released estimands, model specifications, validation membership, thresholds, and numerical tolerances unless the change explicitly introduces a new analysis.
